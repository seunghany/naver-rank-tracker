# 사진 보관함

여기에 넣어두면 초안의 `<!-- 📷 ... -->` 지시와 짝을 지어 쓸 수 있다.
파이프라인이 자동으로 업로드하지는 않는다 — 발행할 때 사람이 올린다.

```
content/photos/
├─ reboot/
│  ├─ facility/    센터 전경, 샤워실, 파우더룸, 12.5m 레인
│  ├─ equipment/   스키에르그, 로잉, 슬레드, 월볼, 샌드백, 케틀벨
│  ├─ class/       수업 장면, 코치 지도 컷
│  ├─ members/     회원 사진 (동의 받은 것만)
│  └─ misc/
└─ teampoise/      같은 구조
```

## 파일 이름 규칙

`<주제>-<설명>-<순번>.jpg`

```
facility/shower-booth-01.jpg
facility/sled-lane-12m-01.jpg
equipment/skierg-row-01.jpg
```

초안에서는 이렇게 지시한다.

```markdown
<!-- 📷 facility/sled-lane-12m-01.jpg — 레인 길이가 한 장에 들어와야 함 -->
```

## 찍을 때

- **가로로 길게** — 네이버 블로그는 가로 사진이 잘 붙는다. 12.5m 레인처럼 길이를 보여줄 땐 특히
- **사람 없이 or 동의받고** — 회원이 식별되는 사진은 반드시 동의를 받고 `members/` 에 둔다
- **같은 날 찍은 티가 나게** 몰아 찍지 말 것 — 계절·조명이 다른 사진이 섞이면 꾸준히 관리되는 느낌이 난다

## AI 생성 이미지

시설·장비·회원 사진은 **실물만** 쓴다. 이유는 `docs/AUTOMATION.md` 부록 참조.
도해·인포그래픽(예: 8개 스테이션 순서도)은 만들어 써도 된다.
